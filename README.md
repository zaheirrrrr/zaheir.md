## What this is

`zaheir.md` is a single Markdown file written for AI agents as well as people.
When a recruiter, hiring manager or collaborator asks an AI assistant about me, the assistant can load this file and get accurate, sourced facts instead of guessing.

The file follows the `AGENTS.md` convention:

- short statements of fact about my experience, education and skills
- rules telling an agent how to use those facts, such as quoting figures exactly and pointing to me for anything the file doesn't cover
- links to the authoritative source for everything else, with LinkedIn as the full work history

## How to use it

**With an AI assistant:** paste the raw link into a chat and ask your question, for example:

> Read https://raw.githubusercontent.com/zaheirrrrr/zaheir.md/main/zaheir.md and tell me whether Zaheir fits a part-time event operations role.

**As a person:** open [zaheir.md](./zaheir.md) on GitHub, where it renders as a formatted page.
